# Pending validation (target 2026-10-04)

**v2.0.1 kernel rebuild hotfix — apply, verify, undo.** Return to
[v2.0.1 known issues and hotfixes](../TROUBLESHOOTING.md#v201-known-issues-and-hotfixes).

This procedure is prepared for hardware validation; it is not yet a validated user hotfix.
Publication requires a cold Torch-cache boot and a second boot retaining that cache on all three Sparks,
with no compilation on the second boot. The target date is not a completion claim.

**Symptom and cause.** Every start installs the engine wheel into a new container
([v2.0.1 scripts/serve.sh:125–126](https://github.com/jakejharris/jspark3/blob/v2.0.1/scripts/serve.sh#L125-L126)).
Pip's fresh compiler-source timestamps trigger redundant Ninja compilation even when the cache is retained.
The affected path delegates to Torch's extension loader
([engine/src/tensorfold/cuda/build.py:23–29](https://github.com/jakejharris/jspark3/blob/v2.0.1/engine/src/tensorfold/cuda/build.py#L23-L29));
the cache persists through the mount at
[scripts/serve.sh:114–116](https://github.com/jakejharris/jspark3/blob/v2.0.1/scripts/serve.sh#L114-L116)
and [config/serve.env:61](https://github.com/jakejharris/jspark3/blob/v2.0.1/config/serve.env#L61).
Skipping this hotfix leaves the slower starts and repeated exposure to the
[hypothetical interrupted-compile lock](../TROUBLESHOOTING.md#possible-stale-torch-extension-lock).
Applying it does not recover an existing lock.

The patch below adapts reviewed F1 commit `8870a7a3dcacf3deefe7a5b06c8cdf16fb98bffb`:
its 75-line helper is unchanged, and the only existing-line edit invokes it after pip and before engine launch.
Both independent F1 reviews returned **MERGE-OK**, explicitly limiting their evidence to host pip/Ninja tests,
not CUDA cache reuse. The helper verifies the wheel content pin and installed compiler-source bytes before
restoring their ZIP timestamps using UTC. It does not change source bytes or cache timestamps. Its pin format
matches [v2.0.1 scripts/wheel-content.py:11–19](https://github.com/jakejharris/jspark3/blob/v2.0.1/scripts/wheel-content.py#L11-L19).
The helper is included in full here; no private repository or download is needed.

## Before applying

Use Bash in the root of the **v2.0.1 tagged recipe checkout**, not the separate main/docs checkout.
The commands require Git, Python 3, `sha256sum`, Docker and sudo for cache files. Complete the
[install preparation](../../INSTALL.md#quick-start-base-weights-the-default) through wheel build and splitting
first. Use the same installed wheel and settings throughout both boots.

Record your chosen weights, drafter, session tier and container prefix in `cluster.env` on each box,
with the same choices on all three; the commands below use those settings without CLI overrides
([scripts/lib.sh:128–135](https://github.com/jakejharris/jspark3/blob/v2.0.1/scripts/lib.sh#L128-L135)).
If a current run used a CLI-only prefix, stop that run with its matching `--container-prefix` first.
Save any needed Docker logs before stopping: the ordinary stop removes the container
([scripts/stop.sh:46–48](https://github.com/jakejharris/jspark3/blob/v2.0.1/scripts/stop.sh#L46-L48)).

Run on **each box**, then wait until all three have stopped:

```bash
scripts/stop.sh
```

Prevent automatic/concurrent restarts throughout apply, cache moves and undo. Stop any host Python/build jobs
using this cache too. The checks below refuse any running container on the local Docker daemon; they cannot
prove that another Docker daemon or a host process is idle. Do not proceed unless all cache users are stopped.
Run each block in order, on the boxes specified, and stop at any error.

```bash

--- a/scripts/serve.sh

@@ -125,3 +125,3 @@

+++ b/scripts/fabric/restore-source-mtimes.py

+#!/usr/bin/env python3
+"""Restore verified compiler-source mtimes after pip installs the pinned wheel.
+
+Pip gives extracted files new mtimes. Ninja then rebuilds byte-identical sources
+even when a matching cache is mounted. Use the same wheel timestamps in seed and
+serve containers, before importing the engine. Never alter source/cache bytes.
+"""
+import argparse
+import datetime
+import hashlib
+import importlib.metadata
+import json
+import os
+from pathlib import Path, PurePosixPath
+import zipfile
+
+SOURCE_SUFFIXES = {'.c', '.cc', '.cpp', '.cxx', '.cu', '.cuh', '.h', '.hpp', '.hxx'}
+
+
+def restore(wheel, root, expected):
+    root = root.resolve(strict=True)
+    sources = []
+    with zipfile.ZipFile(wheel) as archive:
+        members = [info for info in archive.infolist() if not info.is_dir()]
+        names = [info.filename for info in members]
+        if len(names) != len(set(names)):
+            raise ValueError('wheel has duplicate members')
+        content = {}
+        for info in members:
+            name = PurePosixPath(info.filename)
+            if name.is_absolute() or '..' in name.parts:
+                raise ValueError('unsafe wheel member: ' + info.filename)
+            digest = hashlib.sha256(archive.read(info)).hexdigest()
+            if not (len(name.parts) == 2 and name.parts[0].endswith('.dist-info')
+                    and name.parts[1] in {'RECORD', 'WHEEL'}):
+                content[info.filename] = digest
+            if name.parts[0] != 'tensorfold' or name.suffix not in SOURCE_SUFFIXES:
+                continue
+            path = root / info.filename
+            if path.is_symlink() or not path.is_file() or not path.resolve().is_relative_to(root):
+                raise ValueError('compiler source is not an installed regular file: ' + info.filename)
+            if hashlib.sha256(path.read_bytes()).hexdigest() != digest:
+                raise ValueError('installed source differs from pinned wheel: ' + info.filename)
+            # ZIP timestamps have no timezone; one explicit UTC interpretation is
+            # identical across seed/serve processes and across all three hosts.
+            timestamp = int(datetime.datetime(*info.date_time, tzinfo=datetime.timezone.utc).timestamp())
+            sources.append((path, digest, timestamp * 1_000_000_000))
+        actual = hashlib.sha256(''.join(f'{digest}  {name}\n'
+                                       for name, digest in sorted(content.items())).encode()).hexdigest()
+        if actual != expected:
+            raise ValueError('wheel content digest differs from pin')
+        if not sources:
+            raise ValueError('wheel contains no compiler sources')
+
+    # Validate every source and the wheel identity before changing any timestamp.
+    rows = []
+    for path, digest, timestamp in sources:
+        before = path.stat()
+        os.utime(path, ns=(before.st_atime_ns, timestamp), follow_symlinks=False)
+        if path.stat().st_mtime_ns != timestamp or hashlib.sha256(path.read_bytes()).hexdigest() != digest:
+            raise ValueError('source timestamp/byte verification failed: ' + str(path))
+        rows.append({'path': str(path.relative_to(root)), 'sha256': digest,
+                     'before_mtime_ns': before.st_mtime_ns, 'mtime_ns': timestamp})
+    return {'status': 'VERIFIED_SOURCE_MTIMES', 'wheel_content_sha256': actual,
+            'wheel_file_sha256': hashlib.sha256(wheel.read_bytes()).hexdigest(),
+            'installed_root': str(root), 'source_files': rows}
+
+
+if __name__ == '__main__':
+    parser = argparse.ArgumentParser(description=__doc__)
+    parser.add_argument('wheel', type=Path)
+    parser.add_argument('expected_content_sha256')
+    args = parser.parse_args()
+    installed = Path(importlib.metadata.distribution('tensorfold').locate_file(''))
+    print(json.dumps(restore(args.wheel, installed, args.expected_content_sha256)), flush=True)
PATCH
git apply --check .v201-kernel-hotfix/change.patch
git apply .v201-kernel-hotfix/change.patch
printf '%s\n' \
  '3cf095915eebe1446f42ff5457ab0a2867269a597d17a947b9654cffd1cf13f7  scripts/serve.sh' \
  '93d0126242be7801c80d0025e278488acd89db29cd38a05ff128cd6a6af9fd9f  scripts/fabric/restore-source-mtimes.py' | sha256sum -c -
bash -n scripts/serve.sh
echo 'APPLIED: one startup line and the verified timestamp helper'
)
```

## Verify: cold Torch-cache boot

On **each box**, with all three stopped, move aside any existing Torch extension cache without deleting it.
This tests a cold **Torch extension** cache only; it leaves Triton and session caches alone. The mount and
Torch directory are defined at [scripts/serve.sh:116](https://github.com/jakejharris/jspark3/blob/v2.0.1/scripts/serve.sh#L116)
and [config/serve.env:61–62](https://github.com/jakejharris/jspark3/blob/v2.0.1/config/serve.env#L61-L62).
Keep enough space for both the old cache and newly compiled files. Do not repeat this preparation before the second boot.

```bash
(
set -euo pipefail
source scripts/lib.sh
load_cluster
running=$(docker ps -q)
test -z "$running" || { echo 'Stop all containers first.' >&2; exit 1; }
test -d .v201-kernel-hotfix
test ! -e .v201-kernel-hotfix/cache-path
cache="$DATA/kernel-cache/torch_extensions"
test ! -L "$cache"
[[ ! -e "$cache.before-v201-hotfix" && ! -L "$cache.before-v201-hotfix" ]]
[[ ! -e "$cache.after-v201-hotfix" && ! -L "$cache.after-v201-hotfix" ]]
umask 077
printf '%s\n' "$cache" > .v201-kernel-hotfix/cache-path
if test -e "$cache"; then
  test -d "$cache"
  sudo mv -T -- "$cache" "$cache.before-v201-hotfix"
fi
test ! -e "$cache"
python3 scripts/preflight.py --for serve
)
```

After every box passes preflight, run this block on **rank 2, then rank 1, then rank 0**:

```bash
scripts/serve.sh
```

Rank 0 waits for an API model listing and a one-token answer; followers only report that they have started
([scripts/serve.sh:129–139](https://github.com/jakejharris/jspark3/blob/v2.0.1/scripts/serve.sh#L129-L139),
[scripts/wait-ready.sh:71–98](https://github.com/jakejharris/jspark3/blob/v2.0.1/scripts/wait-ready.sh#L71-L98)).
After readiness, run on **rank 0** with no other client traffic:

```bash
scripts/smoke.sh
```

Require exit 0 and `SMOKE PASS` ([scripts/smoke.sh:2–7](https://github.com/jakejharris/jspark3/blob/v2.0.1/scripts/smoke.sh#L2-L7)).
Then on **each box**, capture the cold result. The inventory below requires compiled objects and libraries;
it records paths, nanosecond mtimes and SHA-256 so a byte-identical recompile cannot pass unnoticed.

```bash
(
set -euo pipefail
source scripts/lib.sh
load_cluster
umask 077
docker logs "${CONTAINER_PREFIX}-rank${RANK}" > .v201-kernel-hotfix/cold.log 2>&1
grep -q '"status": "VERIFIED_SOURCE_MTIMES"' .v201-kernel-hotfix/cold.log
cat > .v201-kernel-hotfix/cache-inventory.py <<'PY'
import hashlib
import json
from pathlib import Path
import sys
root = Path(sys.argv[1])
if not root.is_dir():
    raise SystemExit('FAIL: Torch extension cache is absent')
rows = {}
for p in sorted(root.rglob('*')):
    if p.is_file() and p.suffix in {'.o', '.so'}:
        rows[str(p.relative_to(root))] = [p.stat().st_mtime_ns, hashlib.sha256(p.read_bytes()).hexdigest()]
if not any(p.endswith('.o') for p in rows) or not any(p.endswith('.so') for p in rows):
    raise SystemExit('FAIL: expected compiled objects and libraries')
print(json.dumps(rows, sort_keys=True, indent=2))
PY
# Keep the receipt owned by the login user; sudo is only for reading cache files.
# shellcheck disable=SC2024
sudo python3 .v201-kernel-hotfix/cache-inventory.py "$(cat .v201-kernel-hotfix/cache-path)" \
  > .v201-kernel-hotfix/cold-artifacts.json
echo 'COLD: helper ran, compiled artifacts recorded; rank 0 must also pass smoke'
)
```

artifact, or failed readiness/smoke means **validation failed**: keep the private logs and inventories and
undo below. A faster wall-clock time by itself is not proof of cache reuse. This procedure does not establish
cache coverage for other workloads or settings. Until those hardware results are reviewed, keep this page pending.

## Undo on each box

Save current container logs if needed, run `scripts/stop.sh` on **all three boxes**, and prevent restarts and
host cache users as before. From the same tagged checkout, run this block on **each box**. It refuses to
overwrite later edits. It reverses the exact patch and, if cold preparation was performed, parks the test
cache at `torch_extensions.after-v201-hotfix` and restores the previous cache if one existed. No cache is deleted.

```bash
(
set -euo pipefail
running=$(docker ps -q)
test -z "$running" || { echo 'Stop all containers first.' >&2; exit 1; }
printf '%s\n' \
  '3cf095915eebe1446f42ff5457ab0a2867269a597d17a947b9654cffd1cf13f7  scripts/serve.sh' \
  '93d0126242be7801c80d0025e278488acd89db29cd38a05ff128cd6a6af9fd9f  scripts/fabric/restore-source-mtimes.py' | sha256sum -c -
git apply -R --check .v201-kernel-hotfix/change.patch
if test -f .v201-kernel-hotfix/cache-path; then
  source scripts/lib.sh
  load_cluster
  cache=$(cat .v201-kernel-hotfix/cache-path)
  test "$cache" = "$DATA/kernel-cache/torch_extensions"
  [[ ! -L "$cache" && ! -L "$cache.before-v201-hotfix" ]]
  [[ ! -e "$cache.after-v201-hotfix" && ! -L "$cache.after-v201-hotfix" ]]
  if test -e "$cache"; then
    test -d "$cache"
    sudo mv -T -- "$cache" "$cache.after-v201-hotfix"
  fi
  if test -e "$cache.before-v201-hotfix"; then
    test -d "$cache.before-v201-hotfix"
    sudo mv -T -- "$cache.before-v201-hotfix" "$cache"
  fi
fi
git apply -R .v201-kernel-hotfix/change.patch
printf '%s\n' '83c5818fe87a9669958f3b372737a9228829870bad74df242c5b205659759d75  scripts/serve.sh' | sha256sum -c -
test ! -e scripts/fabric/restore-source-mtimes.py
git diff --exit-code -- scripts/serve.sh
echo 'UNDONE: original v2.0.1 startup restored; verification receipts and test cache retained'
)
```

The original slower startup behavior returns. A previous cache may still contain a stale lock; inspect it
using the [lock entry](../TROUBLESHOOTING.md#possible-stale-torch-extension-lock) before restarting.
Keep the receipt directory and parked cache for diagnosis; do not include their logs in a public report
without inspecting them for local paths and addresses. If restarting, start ranks 2, 1, 0 and repeat rank 0 smoke.
