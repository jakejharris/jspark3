# sparkDash author-protocol receipt

This evidence set records the JSpark3 release build running sparkDash 1.8.5's
`DecodeBench` at commit `e93fc87d54c8699e98b63a764ab260bf9d446c52`.
The author files were unchanged. The wrapper supplied only the endpoint,
served model name, and output paths.

`SPARKDASH-RESULT.json` is the harness result. `VALIDATION.json` is the
source-run validator output. `SOURCE-MANIFEST.json`, `sparkdash_runner.mjs`,
`validate_results.py`, and `ADAPTATION.md` preserve the source identities,
wrapper, validation method, and adaptation statement. `PUBLICATION.json`
selects the headline code-prompt values and records the privacy-only changes
made while moving the receipts into this public release tree.

The original source receipts contain private filesystem and host labels. The
public copies replace only those labels. No prompt, status, token count,
latency, or throughput value changed.
